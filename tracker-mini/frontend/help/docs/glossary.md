# Glossary

### Part of the Mini Tracker Product Documentation

---

## Purpose

This glossary defines common Mini Tracker terms and abbreviations used across the documentation.

---

## Terms

| Term | Meaning |
|----------|---------|
| **ADS-B** | Cooperative aircraft surveillance data used for aircraft and helicopter awareness. |
| **ADS-B Local** | ADS-B data received by the local Mini Tracker receiver and decoder. |
| **ADS-B Network** | ADS-B data received from Internet-based provider sources. |
| **Dashboard** | The main Mini Tracker browser interface used by the operator. |
| **Drone Sky Check** | External service used by Mini Tracker for selected operational synchronization and zone import workflows. |
| **DS110** | Remote ID receiver used by Mini Tracker for supported drone detection. |
| **DSC** | Drone Sky Check. In the Dashboard status bar, DSC indicators show the active tracker position mode. |
| **External Node** | Meshtastic node visible to the gateway but not matched to a configured mission operator. |
| **Gateway** | The local Meshtastic radio connected to Mini Tracker. |
| **HDOP** | GPS horizontal dilution of precision indicator. |
| **Meshtastic** | Radio network used by Mini Tracker for team awareness and operator messaging. |
| **Mission** | Local operational context containing mission objects and team configuration. |
| **Mission Object** | Map object stored in a mission, such as an area, marker, buffer or imported layer. |
| **NodeDB** | Meshtastic radio node database. |
| **OGN / FLARM** | Network traffic awareness source for gliders and compatible light aviation objects. |
| **Remote ID** | Drone identification data transmitted by supported drones and received by compatible receivers. |
| **Traffic Proximity Awareness** | Informational Mini Tracker feature that displays horizontal proximity between detected drones and aircraft. |
| **User LAN** | Wired network interface intended for user-side local network connectivity. |

---

## Status Labels

| Label | Meaning |
|----------|---------|
| **APR** | Approaching. Movement trend indicates decreasing horizontal distance. |
| **CAU / CTN** | Caution proximity state. |
| **DIV** | Diverging. Movement trend indicates increasing horizontal distance. |
| **DSC-G** | Drone Sky Check position mode using GPS. |
| **DSC-M** | Drone Sky Check position mode using manual position. |
| **MON** | Monitor proximity state. |
| **STB** | Stable movement trend. |
| **STL** | Stale track state. |
| **WRN** | Warning proximity state. |
