# Release Notes

### Part of the Mini Tracker Documentation

---

## Current Status

Mini Tracker is currently under active development.

Formal software releases are not yet part of the development process. New functionality is implemented continuously and documented as it becomes available.

---

## Versioning

At the current stage:

- no official release numbering is maintained;
- no public changelog is published;
- development follows a continuous integration approach.

Developer documentation is considered the primary source of truth for implemented functionality.

---

## Future Process

When the project reaches a stable release cycle, this document will be used to record:

- version number;
- release date;
- major new features;
- bug fixes;
- breaking changes;
- migration notes.
